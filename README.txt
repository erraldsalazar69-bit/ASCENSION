PHONE INSTALL INSTRUCTIONS
1. Unzip these files.
2. Create a GitHub public repository (do not include personal health data).
3. Upload all five files to the repository root.
4. Repository Settings > Pages > Deploy from branch > main / (root) > Save.
5. Open the published HTTPS URL in Chrome on Android, then menu > Add to Home screen > Install.
Keep your profile information only inside the installed app, not in GitHub files.
